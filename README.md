# TEC Craft Construction — Website First Pass

A simple static website built for a small, locally owned carpentry business.

## Files
- `index.html` — page structure and copy
- `styles.css` — all styling / responsive layout
- `script.js` — mobile navigation and current year

## Replace before publishing
1. Project-photo placeholders with Timothy Castle's real work.
2. Phone number and email address.
3. Service area.
4. Placeholder service list with the exact jobs TEC Craft Construction wants to advertise.
5. Project names / locations.

## Design direction
The site intentionally avoids:
- animated counters
- fake testimonials
- giant "BOOK NOW" buttons
- stock-contractor imagery
- flashy gradients / effects
- aggressive sales copy

The goal is a quiet, craft-focused portfolio that feels like a real local business.
