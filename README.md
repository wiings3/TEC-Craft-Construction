# TEC Craft Construction

Website for **TEC Craft Construction**, owned and operated by **Timothy Castle**.

## Source of truth

This GitHub repository is the canonical source for the website from this point forward.

Future minor edits should be made here rather than by rebuilding and passing around ZIP files. When the repository is connected to Netlify, pushes to `main` will automatically redeploy the live website.

## Files

- `index.html` — page structure and copy
- `styles.css` — layout, styling, and responsive behavior
- `script.js` — mobile navigation and current year
- `assets/` — project and site imagery

## Workflow

1. Make website changes in this repository.
2. Commit/push changes to `main`.
3. Netlify automatically rebuilds and redeploys the live site.
4. Keep the existing Netlify site URL as the client-facing prototype.

## Design direction

The site should stay understated, local, and craft-focused. Avoid an overly commercial contractor-template feel, fake testimonials, aggressive sales copy, flashy effects, and gimmicky UI.
